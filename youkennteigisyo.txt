1.0はじめに

このセクションではバーチャル・ケミストリー・ラボの開発目的、
対象範囲、用語の定義、および参照資料について説明します。
1.1  開発目的
		本仕様書は、理科教員や設備が不足する小学校や中学校に対し、
安全かつ質の高い化学実験の機会を低コストで提供することを
目的としています。
3Dプリントで作成した実験アイテムに内蔵されたマイコン(ESP32)とセンサーにより、
「振る」「傾ける」といった動作を検知し、そのデータを基に化学反応の処理を実行します。
この反応結果は、PCのWeb画面上にリアルタイムで表示・再現されます。
これにより、危険な試薬を使うことなく安全性を確保しつつ、
特に座学を好まない中学生の学習意欲を高め、化学への深い理解と探究心を
育む体験型学習環境を実現します。
小学生5〜６年生から中学生3年生までを対象としています。
1.2  範囲
本仕様書は、バーチャル・ケミストリー・ラボのソフトウェアとハードウェアに係る部分を適用範囲とします。

2.0 VCL全体概要
このセクションでは、VCLのコンセプトと提供する価値について説明します。
2.1  疑似実験
VCLは、3Dプリンターで作成した疑似アイテム（コントローラー）とPCを連携させ、化学実験をリアルタイムに再現するシミュレーションシステムです。
疑似アイテムに内蔵されたESP32マイコンが、ジャイロセンサー等の情報を取得し、Wi-Fiを通じてPCへデータを送信します。

入力（物理的操作）:
ユーザーがフラスコや試験管の形をしたデバイスを操作すると、内蔵センサーがその動きを読み取ります。

  - 試験管・フラスコ
    6軸ジャイロセンサーで傾きや加速度を取得し、画面内の3Dモデルと動きを同期させます。
    「振る（撹拝）」「傾ける（注ぐ）」といった動作をリアルタイムに反映します。

  - コンロ（加熱器）
    フラスコなどのデバイスがコンロ上に設置されたことを検知し、加熱プロセスを制御します。

処理（デジタル計算）:
受信したセンサーデータ（傾き、振動、接近等）を基に、バックエンドのNode.jsサーバーが化学反応の進行（温度上昇、色の変化、沈殿の生成）を計算します。

出力（結果の再現）:
計算結果はPC画面上の3D空間（Three.js）に反映され、液体の色が変化したり、泡が発生したりする様子が視覚的にフィードバックされます。


2.2  技術スタック

このプロジェクトでは以下の技術スタックを採用して開発を行います。

- ハードウェア（実験用アイテム）
  - マイコン: XIAO ESP32C3
  - 言語: Arduino (C++)
  - 通信: UDP / WebSocket (Wi-Fi)
- バックエンド
  - ランタイム: Node.js
  - フレームワーク: Express
  - データベース: SQLite
- フロントエンド
  - ビルドツール: Vite
  - 描画ライブラリ: Three.js
  - 言語: JavaScript (ES Modules)

2.3  システムアーキテクチャ

本システムは、保守性と拡張性を確保するため、以下のアーキテクチャを採用します。

1. 三層アーキテクチャ
   バックエンドは「Controller（制御）」「Service（ビジネスロジック）」「Repository（データアクセス）」の三層に厳密に分離し、責任の所在を明確化します。

2. リアルタイム通信フロー
   - デバイス層: ESP32がセンサー値（ジャイロセンサ）を取得し、UDPブロードキャストまたはWebSocketを通じてサーバーへ送信。
   - サーバー層: Node.jsサーバーがデータを受信し、化学反応シミュレーションロジックを実行。演算結果をフロントエンドへプッシュ送信。
   - クライアント層: Three.jsが受信データに基づき、試験管の傾きや液体の色変化をリアルタイムでレンダリング。

2.4  差別化点
	既存の競合アプリは自由度が高すぎるあまり、ユーザーから
「なにをすればいいのか分からない」、
「UIが複雑で操作が難しい」
といったレビューが多く見受けられます。
これに対し、VCLでは以下の対策を講じることで差別化を図ります。

1. **段階的な学習モードの提供**:
   初心者向けのガイド付き「セレクトモード」と、自由に実験できる「フリーモード」の二種類を用意し、習熟度に合わせた学習を可能にします。
2. **物理デバイスによる直感的操作**:
   画面内の操作だけでなく、実際に試験管を振る・傾けるといった物理的な動作を伴うことで、より深い没入感と記憶への定着を促します。
3. **丁寧なオンボーディング**:
   初回利用時には必ず「チュートリアル（炎色反応実験）」を実施し、操作方法を確実に習得できるフローを設けます。
3.0 ユーザー機能
このセクションではユーザーのアカウントにまつわる各種機能を記載します。
3.1  マイページ
		マイページでは、ユーザー情報の管理およびアプリケーション設定の変更を行うことができます。

1. **基本情報の変更**
   - **ユーザーネーム/ニックネームの変更**:
     - 登録時と同様のバリデーションルール（記号不可など）が適用されます。
     - ユーザーIDの変更は、システム内での一意性が確認された場合のみ許可されます。
   - **アイコン画像の変更**:
     - 予め用意された「アバターアイコン」の中から選択して設定します（画像のアップロードはセキュリティ及び容量の観点から不可とします）。
   - **パスワードの変更**:
     - 「現在のパスワード」「新しいパスワード」「新しいパスワード（確認）」の3項目を入力し、整合性が取れた場合のみ更新します。

2. **システム設定**
   - **音量調整**:
     - BGM（背景音楽）と SE（効果音）の音量をそれぞれ 0% ～ 100% のスライダーで調整可能です。
     - 設定はローカルストレージに保存され、次回のログイン時にも適用されます。

3. **アカウント管理**
   - **ログアウト**:
     - 現在のセッションを破棄し、ログイン画面へ遷移します。
     - ログイン履歴テーブルにログアウト時刻が記録されます。
   - **アカウント削除**:
     - 「本当に削除しますか？」という最終確認ダイアログを経て、ユーザーデータおよび進捗データをデータベースから物理削除します。
     - 削除後はログイン画面へ強制遷移します。

4. **学習履歴の確認**
   - 獲得したトロフィーの一覧や、実施済みの実験履歴（成功/失敗）を確認できます。
3.2  アカウント作成
サービスを利用するにはアカウント登録が必要です。生徒用と教師用で登録項目が異なります。
入力データのバリデーションルールは以下の通り、記号の使用を禁止し、シンプルに設定します。

**生徒アカウント登録情報**
- **ニックネーム**
  - 文字種: 全角・半角文字（漢字、ひらがな、カタカナ、英数字）
  - 許可記号: **一切不可**
  - 長さ: 3～12文字
  - 必須: はい

- **ユーザーID**
  - 文字種: 半角英数字のみ
  - 許可記号: **一切不可**（ `_` や `-` も不可）
  - 長さ: 8～32文字
  - 必須: はい
  - 制約: システム内で一意であること

- **パスワード**
  - 文字種: 半角英数字
  - 許可記号: **一切不可**（複雑化を避けるため、英数字のみとする）
  - 長さ: 8～32文字
  - 必須: はい
  - 制約: 英字と数字をそれぞれ1文字以上含むこと

- **利用規約の同意**: 必須

**教師アカウント登録情報**
- **氏名**
  - 文字種: 全角・半角文字
  - 許可記号:  **一切不可**（スペースも不可。詰めて記述する）
  - 長さ: 2～20文字

- **ユーザーID / パスワード**:
  - 生徒アカウントと同様のルールを適用（記号不可）。

- **公式メールアドレス**:
  - lg.jp (地方公共団体)
  - ed.jp (教育機関)
  - ac.jp (大学・学校法人)
  上記いずれかのドメインを含むアドレス必須。

削除操作を行うと、サーバー上の個人データおよび進捗データは物理削除されます。
※誤操作防止のため、最終確認ダイアログを表示します。

3.4  ログイン
起動時に未ログイン状態の場合、ログイン画面へ遷移し、ログイン情報を入力します。

1. **入力・送信**:
   - **ユーザーID** または **メールアドレス**
   - **パスワード**
   これらの情報をHTTPS通信でサーバーへ送信します。

2. **一次認証（パスワード照合）**:
   - データベース内のハッシュ化パスワードと照合します。
   - **照合失敗時**:
     - 「IDまたはパスワードが間違っています」と表示。
     - **アカウントロック機能**: 短時間の連続失敗（5回連続）を検知した場合、アカウントを **5分間** ロックします（授業進行への影響を考慮し、短時間に設定）。

3. **二次認証（二段階認証）**:
   - 一次認証成功後、登録済みのメールアドレス宛に **6桁の認証コード** を送信します。
   - **仕様**:
     - 有効期限: 5分
     - 再送間隔: 60秒
     - 入力試行: 3回まで（失敗時はログイン画面へ戻る）
   - ※生徒アカウントも含め、セキュリティ確保のためメールアドレス登録と二段階認証を必須とします。

4. **認証成功**:
   - アクセス用トークン（JWT）を発行し、TOPページへ遷移します。

3.5  ログアウト
マイページ等の「ログアウト」ボタンから実行します。
1. **セッション破棄**: 端末内に保存されたアクセストークンを削除します。
2. **履歴記録**: データベースのログイン履歴テーブルにログアウト時刻を記録します。
3. **画面遷移**: ログイン画面へ戻ります。

3.6  トロフィーシステム
学習の定着と意欲向上を目的として、特定の条件を満たした際にトロフィーを付与します。
獲得状況はデータベースに保存され、マイページで確認できます。

**定義済みトロフィーリスト**

| ID | トロフィー名 | 獲得条件 | 説明 |
|:--|:---|:---|:---|
| 1 | **はじめての一歩** | チュートリアル完了 | 初めてチュートリアル（炎色反応）を最後まで完了する |
| 2 | **実験チャレンジャー** | 実験開始（初回） | セレクトモードまたはフリーモードで初めて実験を開始する |
| 3 | **新米化学者** | 実験成功（初回） | いずれかの実験で「成功」判定を出す |
| 4 | **実験マスター** | セレクトモード全正解 | セレクトモードに収録されている全ての実験を成功させる |
| 5 | **探究者** | フリーモード3回実施 | フリーモードで3回以上実験を行う |
| 6 | **早起きは三文の徳** | 午前中にログイン | 8:00〜12:00の間にログインを行う |

**表示仕様**
- **未獲得時**: アイコンをグレーアウト表示し、獲得条件のみを表示（詳細は伏せる等の演出も可）。
- **獲得時**: カラーアイコンを表示し、獲得日時を記録。

5.0エラーの種類
5.1  デバイスとの通信が確立できない場合
　条件：疑似アイテム（ESP32）からのデータ受信が一定時間途絶えた場合
　要件：
・「デバイスが見つかりません」という旨のエラーメッセージを表示すること
・デバイスの電源確認やWi-Fi接続確認を促す案内を表示すること
・再接続を試みるための「再試行」ボタンを提供すること

5.2   ネットワーク通信（Wi-Fi等）が切断された場合
　条件：PC側のネットワーク通信が行えない状態となった場合
　要件：
　　　・通信が切断されている旨を
　　　　ユーザーが理解できるエラー表示を行うこと
　　　・通信状態を確認するための案内を表示すること
　　　・再試行可能な操作を提供すること

5.3   ジャイロセンサーの動作異常
　　条件：
　　　・センサーから異常な値（すべて0、極端なノイズ等）が検出された場合
　　要件：
　　　・「センサーの状態を確認してください」等の警告を表示すること
　　　・デバイスの再起動を推奨する案内を行うこと

5.4  キャリブレーションが必要な場合
　　条件：水平な場所に置いているにも関わらず、画面上の試験管が傾いている場合
　　要件：
　　　・設定画面または実験画面から「センサー補正（リセット）」を行える導線を提供すること
　　　・補正完了のアナウンスを表示すること

5.5   上記以外でエラーが発生した場合
　　条件 : なんらかのエラーが起きた時
　　要件 :
　　　・ユーザーが理解できるエラー表示を行うこと
　　　・TOPページに戻るボタンを表示すること。















6.0実験の種類
6.1   酸素の発生実験
　物質 : 二酸化マンガン / 過酸化水素水
　反応条件 : 二酸化マンガンに水で薄めた過酸化水素水を注ぐ
　変化後の物質: 酸素
　視覚的な変化 : 激しく泡が出る
　温度変化 : 温度が高い程反応が促進され、酸素の発生速度が早まる
　　　　　　この反応自体が発熱反応なので、反応が始まると試験管などの　　　　　　温度は上昇する
　表示テキスト
	成功：
	失敗：
　安全性 : 密閉すると圧力爆発する

6.2   二酸化炭素の発生実験
　物質 : 塩酸 / 石灰石
　反応条件 : 石灰石に水で薄めた塩酸を注ぐ
   変化後の物質 : 二酸化炭素
　視覚的な変化 : 入れた瞬間白く濁った色に変化
　温度変化 : 発生する二酸化炭素自体の温度変化は小さい
　　　　　　　　　　　　　反応熱による温度上昇、またはドライアイス（固体CO2）
　　　　　　　　　　　　　の昇華(-79℃から)による冷却効果が観察され、吸熱・発熱現象
　　　　　　　　　　　　　として温度変化が起こる （ドライアイス（固体CO2）は、
　　　　　　　　　　　　　常温で気体（二酸化炭素）に直接変わる（昇華する）
　　　　　　　　　　　　　性質がある）
　表示テキスト
	成功：
	失敗：
　　　　　　　　安全性 : 密閉すると圧力爆発する





6.3   金属の溶け方（アルミニウム）
　　　　　　　　物質 : アルミニウム／塩酸
　　　　　　　　反応条件 : アルミニウムに塩酸を注ぐ
　　　　　　　　変化後の物質 : 水素／塩化アルミニウム
　　　　　　　　視覚的な変化 : 激しく泡が出て時間とともに溶液が黒く濁り、
　　　　　　　　　最終的に透明になる
　　　　　　　　温度変化 : 反応によって温度が上昇する
　　　　　　　　安全性 : 微量の水素ガスが発生するため引火に注意


　　　　　　







6.4   食塩水の蒸発
　　　　　　　　物質 : 食塩水
　　　　　　　　反応条件 : 蒸発皿に入れて加熱する
　　　　　　　　変化後の物質 : 塩化ナトリウム
　　　　　　　　視覚的な変化 : 水が蒸発すると白い結晶が現れる
　　　　　　　　温度変化 : 濃度上昇により沸点が100℃より高くなる
　　　　　　　　安全性 : 高温によるやけどに注意する


6.5  炭酸水素ナトリウムの加熱（熱分解）
　　　　　　　　物質 : 炭酸水素ナトリウム
　　　　　　　　反応条件 : 試験管に入れて加熱する
　　　　　　　　変化後の物質 : 炭酸ナトリウム／水／二酸化炭素
　　　　　　　　視覚的な変化 : 火が消え石灰水が白く濁り塩化コバルト紙が赤色になる
　　　　　　　　温度変化 : 吸熱反応で約270℃から分解が進む
　　　　　　　　安全性 : 加熱による発火や火傷に注意する




6.6  酸とアルカリの性質調べ（中和反応）
　　　　　　　　物質 : 水酸化ナトリウム水溶液／塩酸／フェノールフタレイン溶液
　　　　　　　　反応条件 : アルカリ溶液に指示薬を入れ塩酸を加える
　　　　　　　　変化後の物質 : 塩化ナトリウム
　　　　　　　　視覚的な変化 : 赤色から無色に変わり蒸発させると結晶が現れる
　　　　　　　　温度変化 : 中和反応により温度が上昇する
　　　　　　　　安全性 : 液体の飛び散りに注意する
6.7  石灰水と二酸化炭素の反応
　　　　　　　   物質 : 石灰水／二酸化炭素
　　　　　　　　反応条件 : 二酸化炭素中に石灰水を入れる
　　　　　　　　変化後の物質 : 炭酸カルシウム（多量で炭酸水素カルシウム）
　　　　　　　　視覚的な変化 : 白く濁り二酸化炭素が多いと透明になる
　　　　　　　　温度変化 : わずかに温度が上昇する
　　　　　　　　安全性 : アルカリ性のため目に注意する
6.8  マグネシウムの燃焼
　　　　　　　　物質 : マグネシウム／酸素
　　　　　　　　反応条件 : 加熱して燃焼させる
　　　　　　　　変化後の物質 : 酸化マグネシウム
　　　　　　　　視覚的な変化 : 強い白色光を放ち白い粉末が残る
　　　　　　　　温度変化 : 約2200℃まで急激に上昇する
　　　　　　　　安全性 : 強光と高温による危険がある









6.9  硝酸銀水溶液の反応（塩化銀の生成）　　
 　　　　　　　　物質 : 硝酸銀溶液／塩化ナトリウム
 　　　　　　　　反応条件 : 混合する
 　　　　　　　　変化後の物質 : 塩化銀
 　　　　　　　　視覚的な変化 : 白い沈殿ができ光で黒く変色する
 　　　　　　　　温度変化 : ほとんど変化しない
 　　　　　　　　安全性 : 皮膚に付着すると黒くなる


6.10 酸化銅の還元（炭素による還元）　　
　　　　　　　　物質 : 酸化銅／炭素
　　　　　　　　反応条件 : 混合して加熱する
　　　　　　　　変化後の物質 : 銅／二酸化炭素
　　　　　　　　視覚的な変化 : 赤褐色で金属光沢のある銅ができる
　　　　　　　　温度変化 : 高温で反応が進行する
　　　　　　　　安全性 : 一酸化炭素発生の可能性がある


6.11 鉄と硫黄の反応（硫化鉄の生成）
　　　　　　　物質 : 鉄／硫黄
　　　　　　　　反応条件 : 混合物の上部を加熱する
　　　　　　　　変化後の物質 : 硫化鉄
　　　　　　　　視覚的な変化 : 黒色になり磁石に反応しなくなる
　　　　　　　　温度変化 : 激しい発熱反応で温度が急上昇する
　　　　　　　　安全性 : 有毒ガスと高温に注意する
